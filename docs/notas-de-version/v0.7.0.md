# PET-CT local v0.7.0

Primera versión distribuida como paquete de escritorio desde este repositorio.

## Qué cambió

- Punto de entrada único (`PET-CT local`) que abre la aplicación y ejecuta las herramientas como subcomandos; paquetes para Windows y macOS construidos con PyInstaller.
- Caso sintético de demostración (botón "Crear caso de demostración" y adjunto `datos-demo-sinteticos.zip`) para recorrer todo el flujo sin datos de pacientes.
- Todo lo acumulado desde 0.2 hasta 0.6.2: política de anonimización pet-ct-local/0.4, compuerta y cotejo exactos, emparejamiento, SUV según IBSI-SUV con comparación original/limpio vóxel a vóxel, panel antes/después, revisión de píxeles ligada a hashes, paquetes con manifiesto. Detalle en `docs/CAMBIOS.md`.

## Qué se probó

- 25 pruebas sintéticas en Linux y Windows (runner de GitHub) en cada cambio.
- Validación IBSI-SUV: 58 de 58 objetos de referencia públicos.
- Prueba de humo del ejecutable en los runners de Windows y macOS: herramientas por subcomando, servidor local, importación del caso sintético, cotejo, emparejamiento, comparación SUV y empaquetado.
- Diez casos reales PET/CT en el Mac de Arturo: 10/10 pares compatibles, 10/10 copias idénticas byte a byte, factor SUV conservado en todos los cortes PET.
- Pendiente antes de publicar este borrador: prueba manual en Windows 10 y macOS reales (instalación, selector de carpetas, flujo completo con el caso sintético).

## Limitaciones conocidas

- Los píxeles no se inspeccionan automáticamente: la revisión de píxeles es manual y es requisito antes de compartir; la cabeza está en el campo de visión de los estudios de cuerpo completo.
- Los paquetes no están firmados: SmartScreen y Gatekeeper piden confirmación la primera vez.
- Ventana nativa (`ventana.py`) experimental, fuera del paquete.
- Campos CS y numéricos no se inspeccionan; clases Enhanced y Segmentation permitidas pero no validadas con muestras reales.
